1 · Summary

The system takes a patent number and returns its chemistry as a table. It reads the patent document. It extracts every assay value. It then finds the identity of each compound, because a patent names a compound in several different ways. It checks each structure against the mass the patent printed itself. Today it holds 119,306 assay records from 137 patents, and it has resolved 24,506 compounds to a structure. The largest remaining group is compounds that the patent only draws. That group needs image recognition, and image recognition needs GPU time.

2 · How it works

The three loops, and why each is judged differently. A loop never asks the model for data. It asks for a rule, sends the smallest fragment that still explains the failure — a header and two or three rows, a few hundred tokens rather than the document — then applies the answer to that patent alone and measures what changed. Nothing is scored before it runs; the gate is the measurement.

LoopWhat fires itWhat it asks forWhat keeps it
Table layout A block produced no usable measurement, or a column carries values with no name. One regex-shaped rule: a column map, a bin key, a value pattern, or "this column is not an assay". Re-running the patent with the rule applied and counting what comes out. A rule that reads no more records than the reader already did is discarded.
Chemical name The document asserts a name — in a <heading> or a cid | Name row — and OPSIN refuses it. Not every rejection: 67% of the 82,398 failing seeds are hyphenated English, which the parser is right to refuse. A repair keyed to OPSIN's own error, not to the name. Where no pattern can express the defect, the model writes Python instead. Three conditions, not one. "It parses now" proves nothing: trimming one to eight characters off a failing name makes 13.9% of them parse, because most truncations of a valid name are valid names. Deleting -2-yl turns pyridin-2-yl into pyridine, and OPSIN certifies it.
Markush assembly A table states a shared scaffold and columns of substituents, and never a whole molecule. Nothing is malformed; there is simply no structure until the pieces are joined. An assembly plan — which substituent slot joins the scaffold at which atom. Three checks the table itself supplies: the row's printed m/z; a held-out name compared by InChIKey; and cross-row invariance — every row shares the scaffold and none is identical. A slot wired nowhere makes every row identical, which is the failure that looks most like success.

A rule is keyed to a fingerprint of the defect, never to the patent, so one purchase serves every document that fails the same way. The shipped library holds 172 rules: 62 column maps, 49 bin keys, 35 value patterns, 16 escalations, 9 not-an-assay and 1 row regex. Three paid attempts per layout, capped at $0.20 a patent.

The parts. Each file does one job. No file calls a model except the three loops.

FileWhat it does
sources/uspto_xml.pyReads the patent XML. Builds a grid for each table. A patent splits one table into several fragments, so this joins them into one grid and finds the header rows.
sources/uspto_assays.pyDecides what each column holds: a compound number, an assay, a unit, a run count. Writes one record per value.
sources/bin_legend.pyReads the legend. Turns a grade such as +++ into a numeric range. Seven written forms appear in this corpus.
sources/cid_first.pyThe identity route. Starts at a compound number and searches the document for the name beside it.
sources/iupac_names.py
sources/table_names.py		 Read a name from a heading, and from a table cell.
sources/opsin.pySends a name to OPSIN. Returns a structure, or nothing. OPSIN either parses a name or refuses it, so it is the identity gate.
sources/mass_gate.pyWeighs the structure. Compares it with the mass the patent prints in that compound's own row or section.
repair/The three loops above.
repair/plausibility.pyAudits the output. Every check states something that cannot be true of real data, and none needs reference data.

What a run writes. One command reads the patents and writes all of it: python3 -m patentdb3.verify --all --dump. Add --no-heal to run the reader alone, which costs nothing.

FileHolds

out/structures.tsvOne row per compound identity. Name, SMILES, InChIKey, route, mass verdict.
out/latest.jsonThe manifest. It names the run, the patents, the counts, and whether the loops ran.

The two tables join on the compound number. The reader and the identity routes read that number from different places, so the join is checked: over the compounds BindingDB also holds, 99.3% carry a value that belongs to that molecule, and no pair is swapped.

4 · What is left

44,923 compounds carry an assay value. 22,639 already hold a structure. Most of the rest are not a reading failure. They are drawings that have not been through recognition. That is a compute queue, not a defect.

The drawn compounds are the largest item, and nothing about them is unsolved. A sample of 166 drawings over 33 patents scored a per-patent median of 100% against the masses those patents print. Recognition needs a GPU, and it is decoupled: the pipeline writes a job, a machine reads it, the pipeline reads the answers back. What is missing is compute, not code.

The remaining work is concentrated. Of 137 patents, the top 40 hold 91% of it and the top 10 hold 53%. The pipeline stops on particular documents rather than reading badly everywhere.

6 · Decisions taken

DecisionReason
BindingDB is reference onlyThe only evidence that may correct a structure is what the patent itself printed.
OPSIN is the identity gateIt either parses a name to a structure or refuses. A compound we report is one the nomenclature supports.
Ask the model for a rule, never for dataA rule is small, checkable, and reusable. Re-reading a document to emit data costs about $8.81 a patent.
No LLM vision for markush structuresThe recogniser already reads the R-group labels off the drawing. The mapping is a lookup, not a perception task.
Model confidence is not a quality signalMeasured on 67 images. Correct and incorrect reads overlap completely.
Skip data rather than ship it wrongA wrong record cannot be told from a right one downstream. A missing one can.

7 · Next steps

  1. Get GPU time for structure recognition. 12,666 compounds wait on compute, not on new work. This is the largest gain available and the method is measured.
  2. Read the legend that sits beyond the window. One patent, 5,753 grades.
  3. Read the wavy cut bond. 968 compounds. The patent usually explains its own convention in prose, and a loop that reads that prose is the general answer.
  4. Triage the 860 mass contradictions. Each is a wrong name or a wrong compound number.
  5. Ask Google Patents for the names OPSIN dropped. 1,752 compounds carry a name that never became a structure. They already have a compound number, so anything recovered there joins to its assay values. It is a second opinion, taken after our own routes run.
