1 · Summary

The system takes a patent number and returns its chemistry as a table. It reads the patent document. It extracts every assay value. It then finds the identity of each compound, because a patent names a compound in several different ways. It checks each structure against the mass the patent printed itself. Today it holds 116,007 assay records from 137 patents, and it has resolved 24,948 compounds to a structure. The largest remaining group is compounds that the patent only draws. That group needs image recognition, and image recognition needs GPU time.

4 · Decisions taken

DecisionReason
No LLM vision for markush structuresThe image recogniser already reads the R-group labels off the drawing. The mapping is a lookup, not a perception problem.
No dedicated markush modelMarkushGrapher-2 scores 48–56% on its authors' own benchmarks. That is below what we already measure.
Model confidence is not a quality signalMeasured on 67 images. Correct and incorrect reads overlap completely.
BindingDB is reference onlyThe only evidence that may correct a structure is what the patent itself printed.
Judge each row, not each tableUnder one plan, 527 of 561 molecules were confirmed and 34 contradicted. The failures were per drawing, so the verdict is per row.
Keep molecules nothing can verifyRefusing them deleted 38 correct molecules on a patent that prints no masses. Absence of evidence is now recorded as such. Evidence against is still fatal.
